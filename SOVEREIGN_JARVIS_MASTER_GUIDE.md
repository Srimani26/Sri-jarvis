## 8. UNBREAKABLE ZERO-SHUTDOWN & OFFLINE MOBILE RESILIENCE

### Can Master Sri use J.A.R.V.I.S. if the PC is shut down?
**YES.** Here is how the dual-layer architecture guarantees 100% availability:

1. **Service Worker PWA Caching (`public/sw.js`)**:
   - The entire J.A.R.V.I.S. interface is cached on Master Sri's mobile device as a Progressive Web App (PWA).
   - Even with zero Wi-Fi or when the primary PC is completely turned off, the app shell opens instantly without "This site can't be reached" errors.

2. **On-Device Mobile Core (`src/lib/offline-core.ts`)**:
   - If the main server cannot be reached, the Autonomous On-Device Mobile Core takes over.
   - It performs immediate local intent parsing, handles core inquiries, math, and status questions.
   - Any complex orders or multi-agent tasks are safely queued in `localStorage`. As soon as Master Sri powers on his PC, the queue synchronizes and executes automatically.

3. **Fallback Neural Speech**:
   - If the backend TTS server is offline, J.A.R.V.I.S. automatically routes vocal speech through the mobile device's native browser SpeechSynthesis engine. J.A.R.V.I.S. still speaks out loud!

4. **Process Zero-Crash Shield (`server.mjs`)**:
   - Global `uncaughtException` and `unhandledRejection` monitors catch all transient socket drops and runtime exceptions, preventing crashes.
